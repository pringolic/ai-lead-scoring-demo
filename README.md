AI Lead Scoring Demo

This repository contains a simplified AI-driven lead scoring pipeline
built as part of an internship assignment.

The demo simulates how potential business leads can be ranked based on
role relevance, company funding stage, scientific activity, and location.

Tech Stack:
- Python
- Pandas

Workflow:
1. Sample lead data is created
2. A weighted propensity-to-buy score is calculated
3. Leads are ranked based on the score
4. Results are exported for verification via Google Sheets

This project is designed to be reproducible and easy to extend.
